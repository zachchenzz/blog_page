# Zach Blog

A modern personal blog built with plain HTML, CSS, and JavaScript.

## Features

- Responsive layout
- Dark/light mode
- Modern glassmorphism design
- Blog cards
- About section
- Project section
- GitHub Pages ready

## Local Preview

Open `index.html` directly in your browser, or use VS Code Live Server.

## Deploy

Push this repository to GitHub and enable GitHub Pages from:

Settings → Pages → Build and deployment

Choose either:

- Deploy from a branch: `main` and `/root`
- GitHub Actions: use `.github/workflows/deploy.yml`

## Customize

Replace:

- Name
- Blog posts
- Project cards
- GitHub/LinkedIn/email links
- Avatar
